No `curl` on `PATH` → `update: curl not found` and exit 2.
   2. *Asset naming:* `lastcall-<version>-<target>` where `<target>` ∈ `aarch64-apple-darwin`, `x86_64-apple-darwin`, `x86_64-unknown-linux-gnu`, `aarch64-unknown-linux-gnu` (deliverable 3's matrix), plus `SHA256SUMS`. The host's target is `env!("TARGET")`-equivalent (compile-time `cfg` on `target_arch`/`target_os`); an absent asset for the host → `no release asset for <target>`, exit 2.
   3. *Verify, then replace:* `fs::canonicalize(current_exe())` **first** (macOS `current_exe` returns the symlink path, so temp and target must both be canonical or a symlinked binary fails `EXDEV` after the download); before any network call, probe write permission with `<canonical dir>/.lastcall-update-probe` (`cannot write <dir>: permission denied`, exit 2); download the asset and `SHA256SUMS` to `<canonical dir>/.lastcall-update-<pid>` (same filesystem as the binary, `O_EXCL`, `0o755`), verify the digest with `sha2` (the engine's dependency already), `fs::rename` over the canonical path, print `lastcall 0.1.0 → 0.1.1`; a mismatch exits 1 with `checksum mismatch`, and a `Drop` guard removes the temp file on **every** error path. macOS keeps the running process on the old inode exactly as Linux does; no re-signing (ruling P3).
   4. *Refusals, before any network call:* `current_exe` under `/opt/homebrew/`, `/usr/local/Cellar/` or `/home/linuxbrew/` (following links) → `installed by Homebrew — run: brew upgrade lastcall`; under `~/.cargo/bin/` → `installed by cargo — run: cargo install --git https://github.com/aarontimko/lastcall --force` (the crate is not on crates.io, and nothing on disk says how it was installed); under `/nix/store/` → the nix line. Exit 2, nothing fetched. Unit-tested on the path strings.
   5. *`--check`:* prints `up to date (0.1.0)` or `0.1.1 available — run: lastcall update`, exit 0 either way; never writes the binary.

Failure is silent at info level in the log. `LASTCALL_UPDATE_CHECK=0` is **not** added — the config key is the switch (ruling P2).
