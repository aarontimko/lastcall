## Rulings (PROPOSED — Rec/Alt; the sponsor's verdicts freeze them)

- **P1 What "the Claude Design pass" is.** Rec: a Fable design reviewer with `tui.md` "Design pass inputs" as the brief and the 49 snapshots as the material, run at the kickoff beside the adversarial design review; output `z_ignore/review-phase9/design-pass.md`, one item per brief row with a proposal and a mock frame, ranked; the sponsor rules per item in the same numbered round as these; accepted items become deliverable 6's list. Alt: skip the pass and take only the fixed inputs (`v mark`, the header ellipsis, the two hold rows) — right if the sponsor's "perfectly usable as-is" still holds after the Gate 8 run and v0.1.0 should ship sooner; the brief stays for a v0.2 pass.
- **P2 How `lastcall update` talks HTTP.** Rec: `curl` as a subprocess, herdr's way — no new crate tree in a binary whose whole dependency surface is audited by `cargo tree`; `curl` ships on every macOS and nearly every Linux the install doc targets; a missing curl is a clear exit 2. Alt: `ureq` with `rustls` — no runtime dependency on curl, one fewer moving part in a container; costs ~1.5 MB of binary and a TLS stack to keep updated; right if the sponsor's Linux hosts are minimal images without curl.
- **P3 "Signed binaries" = GitHub artifact attestations + SHA-256, no code signing.** Rec: `actions/attest-build-provenance` gives a Sigstore-backed provenance any user verifies with `gh attestation verify`; `SHA256SUMS` is what `update` checks; herdr ships unsigned binaries and a CLI fetched by curl carries no quarantine attribute, so Gatekeeper never fires; the linker's ad-hoc signature survives `strip = "debuginfo"` (the worker verifies `codesign -dv` on the macOS artifacts). Alt: Apple Developer ID signing + notarization in the release job — right if the install doc will ever say "download in the browser" or a Homebrew cask is next; costs a paid certificate and secrets in the repo.
- **P4 Two tags: `v0.1.0-rc.1` then `v0.1.0`.** Rec: the rc is the clean-machine install, the final tag is the live `lastcall update` — both [sponsor] evidence forms on the real Releases page, no throwaway "test release" left behind, and `update`'s prerelease rule is exercised. Alt: one tag `v0.1.0` and the container smoke's local-server update as the only update evidence — right if the sponsor would rather not have an rc in the Release list; loses the live update proof until v0.1.1.
- **P5 Neighbour-first selection (§6.7).** Rec: below, else above, else the row that takes the emptied root's place (next root's first, else previous root's last), else nothing — the sponsor's ask, in nav order so that what moves is what the eye is on. Alt: below, else above, else nothing (never cross a root) — simpler wording and never a cross-root jump; right if the sponsor prefers a moment of "nothing selected" over landing in another repo after clearing one.
- **P6 Scope jitter: shell `cwd` only for the containment fallback (§6.6).** Rec: a sibling pane's `foreground_cwd` stops moving the scope; agent association keeps `foreground_cwd`; one sentence in §6.6. Alt: keep `foreground_cwd` and debounce narrowing by 2 s (widening immediate) — right if the sponsor `cd`s inside subshells or tools that change the *foreground* cwd without the shell's, which shell-cwd-only would miss; costs a timer and a test for it.
- **P7 The perf gate numbers and the metric rename.** Rec: the table above (run D–F + headroom, everything far under run A), `first_pile_ms` → `first_checked_ms`, run G on a quiet machine twice as the evidence. Alt: targets = run A × 0.8 (the literal "20 %" reading) — trivially met and meaningless after the Phase 5 pool; right only if the sponsor wants the gate to be a floor against catastrophe rather than a ratchet.
