6. **Draw discipline (TUI).**

   - (b) *No-op herdr draws:* `HerdrUpdate::Roots` returns `Changed::Yes` only when `apply_roots` changed a flag, status, pane or label of any root (add `ReadyDelta::changed: bool`, set whenever `next != self.roots` before the swap) — the toast request keeps its current shape.

## Rulings (sponsor decides before the freeze)

1. **Collapsed-row expansion.** Rec: on-demand expansion for `Glob` and `Size` rows via `e`, computed lazily with a 2,000-line cap, whole-row accept only (deliverable 4) — D7's "no hunk view *by default*" reads as "there is one on request", and the placeholder text has been promising it since Phase 3. Alt: keep the placeholder, reworded to `collapsed (<kind>) · +a −d` with no expansion, and let Phase 8 (editing) decide — right if the sponsor never wants to read a lockfile diff in lastcall; costs nothing now.
2. **Debounce starvation cap.** Rec: a 3 s cap (deliverable 10) — the sponsor's core complaint on the Gate 5 run was "nothing until the very end"; a writer that never pauses 750 ms is exactly the case that reproduces it for real, and a scan every 3 s costs ~16 git spawns per root per 3 s at worst. Alt: trailing-edge only, as today — right if one coalesced pile at the end of a burst is what a reviewer wants to read and partial piles during a burst would be noise; the diagnosis showed the agent's actual pattern (one command per batch) never triggers the starvation.
3. **Claude Design pass timing.** Rec: Phase 6 does not wait for the pass; the three named frames stay its input and its findings land on the Phase 8 kickoff agenda, where the screens change anyway — Phase 6 touches the nav and the first frame but not the status line, header ladder or scope notice. Alt: the sponsor runs the pass now, before the worker launches, and its findings become Phase 6 deliverables — right if the pass is a week or less away and its findings would change the nav work in deliverables 7 and 9.
4. **Discovering frame scope.** Rec: deliverable 7 as written (terminal taken before discovery; Ctrl-C during discovery exits 130). Alt: keep `Engine::open` before the terminal and print a single stderr line `lastcall: discovering roots under <dir>…` that the TUI overwrites — a five-line change, right if the blank seconds are acceptable and the loop restructure is judged not worth the risk on a phase that already reshapes the loop (deliverable 6).
5. **Worker split.** Rec: one Opus 5 worker with a sanctioned checkpoint after deliverable 5 — the engine half is small and the TUI half depends on `hunks_of` and the loop shape. Alt: two workers (6a engine 1–5, 10; 6b TUI 4, 6–9) on one branch like Phase 5 — right if wall-clock matters more than the merge cost.
